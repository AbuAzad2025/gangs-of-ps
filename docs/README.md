# مستندات المشروع

هذه المجلدات هي نقطة الدخول الرسمية لشرح بنية المشروع، إعداد البيئة، النشر، وعمليات التشخيص.

## محتويات الوثائق

- [setup.md](./setup.md) — إعداد البيئة المحلية والتشغيل الأولي
- [deploy.md](./deploy.md) — النشر على خوادم الإنتاج/الاستضافة
- [faq.md](./faq.md) — الأسئلة الشائعة
- [troubleshooting.md](./troubleshooting.md) — حلول المشاكل الشائعة
- [structure-guide.md](./structure-guide.md) — دليل كامل لبنية المجلدات والملفات

## الإرشادات السريعة

1. ابدأ بـ [setup.md](./setup.md) إذا كنت تريد تشغيل المشروع محليًا.
2. استخدم [deploy.md](./deploy.md) عند تجهيز النشر.
3. راجع [troubleshooting.md](./troubleshooting.md) إذا ظهرت أخطاء تشغيل أو قاعدة بيانات.
4. استخدم [structure-guide.md](./structure-guide.md) لفهم أين تقع الميزات الأساسية.

## ملاحظات أساسية

- المشروع يعمل محليًا بشكل افتراضي باستخدام SQLite.
- PostgreSQL يدعم الإنتاج عند التهيئة الصحيحة.
- كل ملف وثيقة يجب أن يكون دقيقًا وآخر تحديثاته مطابق لحالة المشروع الفعلية.
- لا تستخدم مستندات قديمة أو نصوص دعائية غامضة في التوثيق الرسمي.

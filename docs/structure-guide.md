# دليل بنية المشروع

هذا الملف يشرح المجلدات والملفات الأساسية في المشروع بشكل عملي، لتسهيل التطوير والصيانة.

## نظرة عامة

المشروع عبارة عن تطبيق Flask يتميز بنية ثلاثية الطبقات: 
- طبقة العرض: templates/ و static/
- طبقة التطبيق: routes/ و services/
- طبقة البيانات: models/ و extensions.py و config.py

## بنية المجلدات الرئيسية

```text
.
├── admin/                  # وحدات إدارة الموقع والتطبيق
├── data/                   # بيانات التدريب والملفات التهيئية
├── docs/                   # وثائق المشروع
├── forms/                  # نماذج Flask-WTF أو نماذج الإدخال
├── models/                 # نماذج SQLAlchemy
├── routes/                 # مسارات Flask والواجهات HTTP
├── services/               # منطق الأعمال والخدمات
├── static/                 # ملفات CSS، JS، صور، فيديوهات
├── templates/              # قوالب HTML / Jinja
├── tests/                  # اختبارات المشروع
├── translations/           # ملفات ترجمة Babel
├── utils/                  # أدوات مساعدة
├── config.py               # إعدادات التطبيق العامة
├── extensions.py           # كائنات الطرف الثالث مثل db و login و babel
├── factory.py              # إنشاء التطبيق الرئيسي
├── run.py                  # نقطة التشغيل المحلية
├── wsgi.py                 # نقطة تشغيل WSGI
├── pyproject.toml          # إعدادات المشروع والأدوات
├── requirements.txt        # تبعيات التشغيل
├── requirements-dev.txt    # تبعيات التطوير
├── README.md               # الملف الرئيسي لوصف المشروع
├── DEPLOY.md               # وثائق النشر
├── AI_INSTRUCTIONS.md       # قواعد التطوير داخل المشروع
└── .gitignore              # ملفات مستبعدة من Git
```

## شرح مهم لكل قسم

### admin/

يحتوي على واجهات الإدارة وقدرة إدارة المحتوى أو الإعدادات.

### data/

يستخدم لتخزين بيانات التدريب والملفات الداعمة مثل ملفات المضيفات/الذكاء أو بيانات النظام.

### docs/

يحتوي على وثائق التشغيل، النشر، FAQ، واستكشاف الأخطاء.

### forms/

يوجد به تعريف النماذج المستخدمة في تسجيل الدخول، النماذج الإدارية، المبيعات، والواجهات التفاعلية.

### models/

يحتوي على نماذج SQLAlchemy للأدوار، المستخدمين، الاقتصاد، الجرائم، والأشياء داخل اللعبة.

### routes/

تستقبل هذا القسم جميع واجهات HTTP الرئيسية مثل:
- تسجيل الدخول
- الصفحة الرئيسية
- الاقتصاد
- الجرائم
- الشات
- الإعلانات/المتاجر
- النظام الداخلي

### services/

يحتوي على منطق الأعمال المنفصل عن الـ routes، مثل:
- خدمة IA/المضيفات
- خدمة الاقتصاد
- خدمة الموارد
- خدمة الترفيه
- خدمة النشاطات والأنشطة

### static/

يحتوي على:
- CSS
- JavaScript
- الصور
- الفيديوهات
- ملفات ثابتة للتطبيق

### templates/

يحتوي على الصفحات HTML وشرائح الواجهة. هذا هو المكان الأساسي لتعديل الصفحات الرئيسية أو القوالب العامة.

### tests/

يحتوي على اختبارات المشروع مثل:
- route tests
- unit tests
- integration tests
- security tests
- smoke tests

### translations/

يحتوي على ملفات Babel لترجمة النصوص إلى لغات متعددة مثل العربية/الإنجليزية.

## ملاحظات للمطور

- لا تضع منطق الأعمال داخل القوالب.
- ضع منطق التشغيل في services/ أو routes/ حسب السياق.
- لا تعدل ملفات مستندات المشروع بشكل عشوائي؛ استخدم الوثائق كمرجع للحالة الفعلية.
- قبل أي تعديل كبير، تأكد من وجود اختبار مناسب أو إجراء smoke check.

## سجل التوافق

- SQLite: مناسب للتطوير المحلي
- PostgreSQL: مناسب للبيئة الإنتاجية
- Flask app factory: يتم إنشاؤه عبر `factory.py`
- التثبيت المحلي: عبر `run.py` أو `flask run`

## نقاط الدخول الرئيسية

- `factory.py` — إنشاء التطبيق
- `run.py` — التشغيل المحلي
- `wsgi.py` — نقطة تشغيل WSGI
- `config.py` — إعدادات التطبيق
- `extensions.py` — إعدادات المكتبات الخارجية

## توصية عملية

عند إضافة ميزات جديدة، حافظ على هذا الترتيب:
1. models/ إذا كانت هناك بيانات جديدة
2. services/ إذا كان هناك منطق أعمال
3. routes/ إذا كانت هناك واجهة HTTP
4. templates/ إذا كانت هناك صفحة أو مكون جديد
5. tests/ لتغطية السلوك
6. docs/ إذا كان التغيير يحتاج شرحًا
